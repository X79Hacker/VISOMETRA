1. Stop your old server with Ctrl+C.
2. Extract this ZIP into a NEW folder. Do not run from inside the ZIP.

6. Open a frame in Curve Studio. Generate a mask or open a saved project.

EDIT YOUR OUTLINE
- Run Fourier / Edit anchors reveals the diamond handles.
- Drag filled diamonds to move anchors.
- Hollow midpoint diamonds insert a point between two anchors. Drag directly
  or use + Point / double-click an edge. Curve subdivision preserves its shape.
- Select an anchor, choose Bezier curve, then drag the circular handles.
- Smooth anchor links tangents; Sharp corner collapses that anchor's handles.
- Arrow keys nudge 1 pixel; Shift + arrows nudges 10. Delete removes a point.
- Undo / Redo includes complete curve edits. Wheel zooms; Space + drag pans.
- Run Fourier or leave Recompute after edits enabled to update the analysis.
