02 Refine the selection

Include / Exclude points are used by points mode. For text mode, enter a description and Create outline.

Clean up mask

Cleanup changes the mask. Undo restores it. Holes are preserved by default.

Shape the boundary

Filled diamonds move anchors. Hollow diamonds add an anchor between two sections. Circular handles bend a curve.

SELECTED ANCHORGenerate a mask to begin.

Smooth links both handles at the selected anchor. Sharp collapses its handles. Other sections keep their own line / curve settings.

Precision & keyboard

Arrow keys: nudge 1 pixel. Shift + arrows: 10 pixels. Delete: remove anchor. Double-click an edge to add a point. Wheel: zoom. Hold Space and drag: pan. Ctrl+Z / Ctrl+Y: undo / redo.

Fourier uses an adaptive polyline within 0.15 image pixels of the Bézier segments. The curve area is integrated analytically. Mask and benchmark exports use a rasterized version of the edited boundary.

SEED MASK → MOTION PROPOSAL → SLIMSAM REFINEMENT

Assisted object tracking

Start with one corrected object mask in the current frame. Nearby translation is estimated from image texture; SlimSAM refines a box and Include point in each next frame. Existing masks are kept and used as new seeds. Weak or ambiguous matches stop the run. New suggestions always need review. This is not a video identity tracker; scale changes, rotation and occlusion can fail.

Use Stop batch / Cancel to stop tracking. Episode projects are saved in the workspace; keep a complete backup for transfer.
