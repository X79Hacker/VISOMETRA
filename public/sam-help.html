Outline Studio V3 / AI tracing

Open Outline Studio V3 →
Bundled text → SAM: type “bench”, Create outline, correct with Paint / Erase, then Apply & run Fourier. CLIPSeg and SlimSAM are included; no extra model setup or API key is needed. Studio preserves the full image, holes and separate objects. Save a complete project to reopen it later.

The included SlimSAM · stable CPU model works immediately. The V2 preview shows one green polygon used by Fourier. It is a different, smaller model than SAM 3.

Enable real SAM 3 on your laptop

  1. Install Python 3.12 or newer if needed.
  2. Request model access at facebook/sam3 on Hugging Face, under your own account.
  3. From the extracted project folder, run setup-sam3-windows.bat. Log into Hugging Face in that local terminal. The approximately 3.44 GB checkpoint downloads separately.
  4. Restart start-windows.bat, reopen Trace or a cell, and choose a SAM 3 engine.

Your RTX 4060 8 GB can run into memory limits. The backend includes CPU offload and handles one image at a time. Choose Fast offline if SAM 3 reports insufficient memory.

Use a result

Add include/exclude points, draw a box, or use a text description in SAM 3 concept mode. Segment, compare mask and boundary, then press Apply & run Fourier, or Use boundary only to keep editing. The existing manual tools can refine it. Finish → Grid on the Trace page, or Compute inside a cell.

Legacy grid measurement limitations

Outline Studio V3 uses multiple closed contours and subtracts holes. The original grid/Trace quick assistant measures one outer contour. PNG masks preserve holes and multiple regions, but the original single-outline grid/Fourier representation cannot represent internal holes. Review the assistant's acknowledgement before importing such a shape.

SAM 3.1 mainly improves multi-object video tracking. This still-image integration uses the documented SAM 3 image models. No model is best for every image.

Complete setup, technical details and validation notes are included in docs/SAM3_SETUP.md in your downloaded folder.
